# Required Images

## Logo
- **File**: `logo.jpg` (in this folder)
- **Usage**: Header navigation, branding
- **Your logo**: The Sardar Ji crown with globe and plane

## Homepage Slideshow
- **Folder**: `Slideshow/`
- **Files**: `1.jpg` through `12.jpg`
- **Usage**: Homepage hero slideshow

## Admin Panel Hero
- **Folder**: `admin-hero/`
- **File**: `admin hero.jpeg`
- **Usage**: Hero image for all admin pages

## Instructions
1. Save your logo as `logo.jpg` in the `public` folder
2. Add 12 slideshow images in `public/Slideshow/` (numbered 1-12)
3. Add admin hero image as `public/admin-hero/admin hero.jpeg`
4. Commit and push to deploy
